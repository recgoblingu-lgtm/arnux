# Arnux App Starter

Copy this folder to start a third-party Arnux app.

1. Add `starter.js` to the Arnux page after `sdk.js`.
2. Register the returned manifest in the `APPS` object in `app.js`.
3. Add a `wireWindow(win, 'starter')` branch for interaction.

The starter demonstrates a logo, placeholder, file permission, local storage, notification, and a reusable render function.
